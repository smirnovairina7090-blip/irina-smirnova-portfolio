# Ирина Смирнова — портфолио методиста-методолога

Сайт, семь избранных проектов и краткое портфолио PDF.

Локальный просмотр: `python -m http.server 8787` из папки репозитория, затем открыть http://localhost:8787.

Сборка и установка зависимостей для просмотра не нужны. Файлы можно разместить на статическом хостинге.

`portfolio.json` — тексты проектов; `index.html` — страница; `style.css` — оформление; `app.js` — интерактивные карточки; `irina-smirnova-portfolio.pdf` — одностраничное портфолио.

В репозитории нет выгрузок закрытых курсов. Планируемые метрики отделены от достигнутых результатов.

Контакт: [@grusha_semenovna](https://t.me/grusha_semenovna).
